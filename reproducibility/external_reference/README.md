# External Benign Reference Comparison

This directory contains the scripts, documentation, and example outputs required to reproduce the descriptive comparison between traffic generated by the LLM-driven regular-user agent and benign traffic from CIC-IDS2017.

The comparison provides an external point of reference. It is not intended to establish distributional equivalence or to claim that the generated traces reproduce the CIC-IDS2017 environment.

## Reference dataset

The public reference is the `Monday-WorkingHours` capture from CIC-IDS2017. This capture contains benign activity only.

The analysis uses traffic associated with the following endpoint:

- Operating system: Windows 10
- IP address: `192.168.10.14`

The LLM-generated captures use the local endpoint:

- IP address: `192.168.18.134`

## Observation unit

The public capture is divided into non-overlapping 900-second windows.

Each LLM run is treated as one nominal 900-second observation. The observed durations are close to 900 seconds, while rate metrics are normalized using the common 15-minute observation horizon.

## Workflow

1. Download `Monday-WorkingHours.pcap` from CIC-IDS2017.
2. Extract traffic associated with the selected Windows 10 host.
3. Reorder the packets chronologically.
4. Divide the public capture into 900-second windows.
5. Build manifests describing the input captures and local endpoint addresses.
6. Apply the same metric-extraction script to the public and generated traces.
7. Aggregate per-window values as median and interquartile range.

## Metrics

The pipeline computes:

- flows per minute;
- packets per minute;
- packets per flow;
- bytes per flow;
- flow duration;
- TCP flow share;
- UDP flow share;
- DNS flow share;
- port-443 flow share;
- packet-size median and p95;
- inter-arrival-time median and p95;
- destination entropy;
- remote-port entropy.

Packet-size values are retained in the example outputs but are not used in the main external-reference table because the CIC-IDS2017 capture contains frames larger than the standard Ethernet MTU, which may reflect capture-side aggregation or offloading.
