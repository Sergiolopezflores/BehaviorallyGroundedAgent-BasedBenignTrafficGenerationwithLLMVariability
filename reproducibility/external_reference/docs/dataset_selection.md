# Dataset selection

The public reference dataset was selected according to the following
criteria:

- publicly available packet captures;
- explicitly labelled benign traffic;
- identifiable hosts;
- sufficient duration to generate multiple windows;
- compatibility with the feature-extraction pipeline.

CIC-IDS2017 satisfies these requirements and provides a widely used
benchmark for cybersecurity research.

The comparison is descriptive and does not assume equivalence between
the generated traces and the reference environment.
